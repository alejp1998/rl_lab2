📖 About this page

🎓 The Lab

Reinforcement Learning Lab 2 (KTH/UPM, 2021) trains a Deep Q-Network on LunarLander-v2 (OpenAI Gym): a neural network (64-64 hidden layers) learns to land a lunar module on a pad, using an experience replay buffer (L=16384), target networks synced every C steps, ε-greedy exploration decaying from 0.99, and N=64 minibatches.

🚀 The environment

This web edition uses a simplified 2D lander with the same reward logic: +100 for a safe landing on the pad (slow descent, small lateral speed), -100 for a crash, -1 per step, fuel consumption for thrusters. Four actions: none, left, main engine, right.

🧠 Learn mode

A DQN (5→64→64→4) trains live in your browser — the exact same recipe as the lab: replay buffer, target network (copied every C=L/N steps), Adam updates and ε-greedy decay. Watch the reward curve climb and the lander learn to hover and settle on the pad. All hyperparameters (γ, α, ε, decay, L, N, speed) are adjustable while it trains.

🎮 Fly mode

Take manual control: ← / → lateral thrusters, ↑ / W / Space main engine. Land with low vertical speed inside the pad area to score +100.

🖥️ Implementation

The lab's dqn.py (network, replay buffer, ε-greedy) was ported 1:1 to JavaScript (rl2-core.js) with a matching node:test suite. Source: github.com/alejp1998/rl_lab2.
